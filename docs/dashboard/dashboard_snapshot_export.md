# Dashboard Snapshot Export

## Purpose

The dashboard snapshot export captures the current filtered state of the Executive Overview page.

## Current Exports

```text
retainai_dashboard_snapshot.md
retainai_dashboard_snapshot.json
retainai_filtered_dashboard_data.csv
```

## Contents

The snapshot includes:

- selected filters;
- KPI values;
- row count;
- generation timestamp;
- source mode.

## Future Evolution

Future versions may add:

- PNG export;
- PDF export;
- HTML dashboard snapshot;
- scheduled dashboard reports.
