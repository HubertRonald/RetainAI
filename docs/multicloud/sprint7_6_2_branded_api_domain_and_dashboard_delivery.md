# RetainAI — Sprint 7.6.2: Branded API Domain and Decoupled Dashboard Delivery

## Architecture

```text
retainai.hubertronald.dev
  → Cloud Run direct domain mapping
  → RetainAI dashboard

api.retainai.hubertronald.dev
  → Namecheap CNAME
  → API Gateway Regional custom domain
  → existing HTTP API
  → existing Lambda backend
```

No Route 53, CloudFront or load balancer is introduced.

## Runtime contract

```text
RETAINAI_API_URL=https://api.retainai.hubertronald.dev
RETAINAI_BACKEND_AUTH_ENABLED=true
RETAINAI_AI_PROVIDER=disabled
RETAINAI_ENABLE_RAG=false
RETAINAI_VECTOR_STORE=disabled
RETAINAI_QUOTA_ENABLED=true
```

The default `execute-api` endpoint remains enabled as a rollback route.

## Dashboard delivery boundary

Terraform manages:

```text
Cloud Run service configuration
service account
Secret Manager integration
public invoker IAM
custom-domain mapping
minimum/maximum scaling controls
runtime API URL
```

Application delivery manages:

```text
Streamlit source code
container build
immutable image tag
Artifact Registry push
Cloud Run image update
new application revision
```

Manual application delivery before Sprint 7.7:

```bash
IMAGE_TAG=sprint7-6-2 \
  /workspace/scripts/deploy_dashboard_cloud_run.sh
```

Sprint 7.7 replaces that manual invocation with GitHub Actions and workload identity federation. Terraform must not be run for each dashboard code change.
